# My Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my skills, experience, achievements, and the various projects I have worked on.

## 🚀 Features

- **Interactive UI**: A highly interactive and visually appealing design with dynamic elements.
- **Responsive Layout**: Designed to work seamlessly across different screen sizes.
- **Sections**:
  - **Hero**: Introduction and prominent call to action.
  - **About Me**: A summary of my background and goals.
  - **Education**: A timeline of my educational background.
  - **Achievements**: Certifications and accomplishments featured dynamically.
  - **CV Integration**: Option to view and download my current Resume/CV.

## 🛠️ Technologies Used

- React.js / Vitest
- HTML5
- CSS3 (Vanilla for precise custom designs)
- JavaScript

## 📦 Getting Started

### Prerequisites

You will need [Node.js](https://nodejs.org/) installed on your machine to run this project locally.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajanikanth45/portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the App Locally

To start the development server, run:
```bash
npm run dev
```

The application will be accessible at `http://localhost:5173/` or your standard local dev port.
